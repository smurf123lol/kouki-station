# Записи микрофона для сценариев

Все три файла — 16 кГц моно PCM16, реальные записи станции (архив
`/var/lib/kouki/audio/station/`), ни одна не больше 100 КБ.

- `ey_gin.wav` — «эй гин», 1.39 с (22240 кадров), 44.5 КБ.
  Сценарий `wake` подаёт его в I2S RX станции (`i2s_wav 1 …`) и ждёт срабатывания
  детектора кодового слова: `распознано «эй гин»` + переход `[FSM: IDLE -> RECORDING]`.
  Детектор глушится первые 2500 мс после старта (`firmware/main/app_wake.c`,
  `kouki_wake_mute(2500)`), поэтому запись идёт после 3 с эмуляционного времени.
- `bystander_speech.wav` — посторонняя речь, 2.62 с, 84 КБ (запись 20261108
  075441, Whisper слышит «Странно работает.»). Сценарий `wake-false-positive`
  понижает порог детектора до 10 % (`serial set_wake_th 10`), получает на этой
  записи локальный хит и проверяет, что ASR-подтверждение его отменяет:
  `ложный хит отменён ASR-проверкой` и возврат в IDLE без SENDING.
- `followup_speech.wav` — речь для окна продолжения, 2.24 с, 72 КБ (запись
  20261108 102055, Whisper слышит «Сейчас.»). Сценарий `followup` подаёт её
  после ответа: `[FSM: DONE -> FOLLOWUP]` → `[FSM: FOLLOWUP -> RECORDING]`.
  Здесь срабатывает не кодовое слово, а спектральная VAD (13 кадров по 30 мс).
