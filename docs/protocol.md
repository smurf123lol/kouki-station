# Протокол: станция → сервер

Станция не знает ни про интенты, ни про команды. Она записывает фразу, отдаёт
её серверу и показывает, что сервер ответил. Вся логика — на сервере Kouki,
ровно как у Telegram-бота.

Исключение одно — **сессия**: станция сообщает, зачем человек нажал кнопку,
потому что «Записать» и «Спросить» — разные намерения, а не разные слова.

## Режимы (сессии)

| Кнопка | Параметр `intent` | Поведение сервера |
| --- | --- | --- |
| Записать | `add_task` | фраза становится задачей целиком, классификатор не участвует |
| Спросить | `ask` | вопрос сохраняется задачей, ответ команды `ask` ложится в `meta.answer` (пока заглушка) |

`kouki_voice_set_session()` вызывается до старта записи; во время записи или
отправки смена сессии возвращает `ESP_ERR_INVALID_STATE`.

## Запрос

```
POST {KOUKI_SERVER_URL}/api/voice?source={KOUKI_SOURCE}[&intent=add_task|ask]
Authorization: Bearer {KOUKI_SERVER_TOKEN}
Content-Type: audio/wav

<байты WAV: PCM16, 16 кГц, моно>
```

Тело — обычный WAV-файл, а не multipart: сервер читает сырое тело и разбирает
заголовок сам (`WavReader`). Требования к формату жёсткие:

| Параметр | Значение |
| --- | --- |
| Контейнер | RIFF/WAVE |
| Кодек | PCM (формат 1) |
| Биты на сэмпл | 16 |
| Частота | 16 000 Гц |
| Каналов | 1 |

Нарушение любого пункта — `415` с текстом причины. Ограничения: тело ≤ 5 МБ,
длительность ≤ 30 с.

## Ответ (200)

```json
{
  "transcript": "Запиши задачу купить хлеб.",
  "confidence": null,
  "durationSec": 2.19,
  "audioPath": "audio/station/20261023/093214_ea4e.wav",
  "intake": {
    "task": { "id": "…", "title": "запиши задачу купить хлеб", "status": "new", "priority": 2 },
    "intent": { "intent": "add_task", "score": 1, "model": "rules-v1" },
    "command": null,
    "executed": false,
    "outcome": "created",
    "result": { "…": "то, что вернула команда, если она была" },
    "error": null
  }
}
```

Что показывает экран по полям:

| Поле | Что значит | Что рисуем |
| --- | --- | --- |
| `transcript` | что услышали | в кавычках мелким шрифтом |
| `intake.outcome` | `created` / `executed` / `needs_review` / `failed` | «Задача записана» / «Готово» / «На разбор» |
| `intake.task.title` | заголовок новой задачи | «Задача: …» (у вопроса — `result.question`) |
| `intake.result.answer` | ответ ассистента на вопрос | статус «Ответ» + текст |
| `intake.command` | имя команды, если исполнялась | «Команда: …» |
| `intake.error` / `error` | причина отказа | «Не вышло» + текст |

## Коды ошибок

| Код | Когда | Текст в `error` |
| --- | --- | --- |
| 400 | пустое тело | «Пустое тело запроса: нужно WAV.» |
| 401 | нет или неверный токен | `unauthorized` |
| 413 | тело > 5 МБ или > 30 с | «Аудиофайл больше 30 секунд.» |
| 415 | не WAV / не 16 кГц / не моно / не PCM16 | конкретная причина от `WavReader` |
| 422 | речь не распознана | «Речь не распознана.» |
| 503 | на сервере не подключён распознаватель | см. `UnavailableSpeechTranscriber` |

Таймаут на стороне станции — 30 с на весь запрос: этого хватает с запасом,
whisper-small на CPU распознаёт 6-секундную фразу за ~4 с.
