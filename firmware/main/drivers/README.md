# Драйверы Waveshare

Здесь лежат драйверы платы из официального примера Waveshare
[`ESP32-S3-Touch-LCD-1.85C`](https://github.com/waveshareteam/ESP32-S3-Touch-LCD-1.85C)
(лицензия Apache-2.0, тексты — в `components/audio_board` и рядом с файлами).

| Папка | Что внутри | Зачем нам |
| --- | --- | --- |
| `exio/` | `TCA9554PWR` — расширитель GPIO по I2C (`0x20`) | сброс LCD и тача идёт через него, без него экран не инициализируется |
| `lcd/` | `ST77916` + `esp_lcd_st77916` — драйвер QSPI-дисплея 360×360 | вывод картинки LVGL |
| `lcd/esp_lcd_st77916/` | порт `esp_lcd` для ST77916 (команды QSPI) | используется из `lcd/ST77916.c` |
| `touch/` | `CST816` + `esp_lcd_touch` — тач по I2C (`0x15`) | нажатие на кнопку |
| `lvgl/` | `LVGL_Driver` — порт LVGL 8.3 на `esp_lcd` | `lv_timer_handler` и буферы отрисовки |

## Правила

1. **Не переписывать без причины.** Это вендорный код, его правки усложняют
   сравнение с примером при следующем обновлении платы.
2. Если пришлось поправить — оставлять комментарий с причиной прямо в месте
   правки.
3. `main.c` вызывает только три функции: `EXIO_Init()`, `LCD_Init()`,
   `LVGL_Init()`; порядок важен (EXIO → аудио-борда → LCD → LVGL).

Аудио-борда живёт отдельно, в `components/audio_board/`: она поднимает I2C,
кодек ES8311/ES7210 и даёт `esp_board_init()` / `esp_get_feed_data()`.
